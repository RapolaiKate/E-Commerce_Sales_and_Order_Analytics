# 📂 E-Commerce Sales & Order Analytics — Datasets

This folder contains the datasets used for the **E-Commerce Sales & Order Analytics** project.

## 📁 Dataset Files

### `E-commerce_Raw_Dataset.csv`

This is the original dataset containing **1,200 e-commerce sales and order records** before data cleaning and validation.

### `E-commerce_Cleaned_Dataset.csv`

This is the final cleaned and validated dataset prepared for analysis and used throughout the project.

It was used for:

* Exploratory Data Analysis (EDA)
* Excel Pivot Table analysis
* SQL analysis
* Power BI visualization

## 📊 Dataset Features

The dataset contains **14 columns**:

* Order ID
* Date
* Customer ID
* Product
* Quantity
* Unit Price
* Shipping Address
* Payment Method
* Order Status
* Tracking Number
* Items in Cart
* Coupon Code
* Referral Source
* Total Price

## 🔄 Data Workflow

```text
Raw Dataset
     ↓
Data Inspection
     ↓
Data Cleaning & Validation
     ↓
Cleaned Dataset
     ↓
EDA
     ↓
Excel Pivot Tables
     ↓
SQL Analysis
     ↓
Power BI Dashboard
```

## 📌 Purpose

The datasets provide the foundation for analyzing sales performance, customer orders, products, payment methods, referral sources, and other e-commerce business metrics.
