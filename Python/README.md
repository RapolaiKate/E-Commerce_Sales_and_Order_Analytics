# 🐍 Python Data Analysis

## Overview

This folder contains the Python analysis for the **E-Commerce Sales & Order Analytics** project.

Python was used to inspect, clean, validate, and explore the e-commerce dataset before performing further analysis using Excel, SQL, and Power BI.

The dataset contains **1,200 records and 14 columns**.

---

## 🔍 1. Data Inspection

The raw dataset was initially inspected to understand its structure and quality.

The inspection included:

* Checking the number of rows and columns.
* Reviewing column names.
* Checking data types.
* Checking missing values.
* Checking duplicate records.
* Reviewing unique values.
* Examining descriptive statistics.
* Identifying potential data-quality issues.

---

## 🧹 2. Data Cleaning

The identified data-quality issues were addressed during the cleaning stage.

The cleaning process included:

* Handling data-quality issues.
* Validating data types.
* Checking duplicate records.
* Checking missing and inconsistent values.
* Validating numerical and categorical fields.
* Preparing the final cleaned dataset.

The cleaned dataset was saved for use in the subsequent analysis stages.

---

## 📊 3. Exploratory Data Analysis (EDA)

EDA was performed on the cleaned dataset to identify patterns and trends in the e-commerce data.

The analysis focused on:

* Sales trends.
* Product performance.
* Order patterns.
* Payment methods.
* Referral sources.
* Quantity and pricing.
* Total sales performance.

Python libraries used for the analysis include:

* **Pandas**
* **NumPy**
* **Matplotlib**
