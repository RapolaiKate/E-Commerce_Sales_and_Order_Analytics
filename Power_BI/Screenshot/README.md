# 📊 Power BI Dashboard Screenshots

## 📌 Overview

This folder contains screenshots of the completed **Power BI E-Commerce Sales & Order Analytics Dashboard**.

The dashboard was created using the cleaned e-commerce dataset containing **1,200 records**.

## 📈 Dashboard Visualizations

The screenshots showcase the Power BI analysis of:

* Total Sales
* Total Orders
* Sales Trends
* Sales by Product
* Orders by Payment Method
* Sales by Referral Source
* Order Status
* Key E-Commerce Sales & Order Metrics

## 🎯 Purpose

The dashboard provides a visual overview of e-commerce sales and order performance, making it easier to identify trends, compare performance, and generate business insights.

## 🛠️ Tool Used

**Microsoft Power BI**
