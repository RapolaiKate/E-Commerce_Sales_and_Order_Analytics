# 📊 Power BI E-Commerce Sales Dashboard

## 📌 Overview

This section contains the **Power BI dashboard** created for the E-Commerce Sales & Order Analytics project.

The dashboard uses the cleaned e-commerce dataset containing **1,200 records** to visualize sales performance, order trends, product performance, payment methods, and referral sources.

---

## 🎯 Objectives

The Power BI dashboard was created to:

* Monitor overall sales performance
* Analyze sales trends over time
* Compare product performance
* Analyze order volume
* Understand payment method usage
* Evaluate referral source performance
* Present key business insights through interactive visualizations

---

## 📊 Dashboard Analysis

The dashboard provides visual analysis of:

* Total Sales
* Total Orders
* Sales Trends
* Sales by Product
* Orders by Payment Method
* Sales by Referral Source
* Order Status
* Other key sales and order metrics

---

## 🛠️ Tools Used

## 💼 Business Value

The Power BI dashboard transforms the cleaned e-commerce data into an easy-to-understand visual report.

It helps users quickly identify:

* Sales performance
* Changes in sales over time
* Best-performing products
* Customer payment preferences
* Effective referral sources
* Order status patterns

These insights can support data-driven business and sales decisions.
