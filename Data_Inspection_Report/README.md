# 🔍 Data Inspection Report

## Overview

This report documents the initial inspection of the **E-Commerce Sales & Order Analytics** dataset before data cleaning and analysis.

The purpose of the inspection was to understand the structure, quality, and characteristics of the raw dataset and identify potential data-quality issues that required attention during the cleaning stage.

## 📊 Dataset Overview

* **Records:** 1,200
* **Columns:** 14
* **Dataset Type:** E-commerce sales and order data

## 🔎 Inspection Areas

The data inspection included:

* Reviewing the number of rows and columns.
* Examining column names.
* Checking data types.
* Checking for missing values.
* Checking for duplicate records.
* Reviewing unique values.
* Examining numerical fields and basic statistics.
* Checking categorical fields for consistency.
* Identifying potential data-quality issues.

## 📋 Inspection Purpose

The inspection findings were used to guide the subsequent **Data Cleaning & Validation** process.

The workflow was:

```text
Raw Dataset
     ↓
Data Inspection
     ↓
Identify Data-Quality Issues
     ↓
Data Cleaning & Validation
     ↓
Cleaned Dataset
```

## 📁 Report

The detailed inspection findings are documented in the accompanying **Data Inspection Report**.

The report forms part of the overall E-Commerce Sales & Order Analytics project.
