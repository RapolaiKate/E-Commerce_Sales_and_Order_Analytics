# 🛒 E-Commerce Sales & Order Analytics

## 📊 Project Overview

This project analyzes **e-commerce sales and order data** to identify sales trends, product performance, customer ordering patterns, payment methods, referral sources, and other key business insights.

The project follows an end-to-end data analytics workflow, starting with data inspection and cleaning and progressing through exploratory analysis, Excel, SQL, and business intelligence visualization.

The dataset contains **1,200 e-commerce sales and order records across 14 columns**.

---

## 🎯 Project Objectives

The main objectives of this project are to:

* Analyze overall sales performance.
* Identify monthly sales trends.
* Analyze sales performance by product.
* Examine order patterns by payment method.
* Analyze sales by referral source.
* Understand order and customer behavior.
* Identify useful business trends and insights.
* Build visualizations that support data-driven decision-making.

---

## 📂 Dataset

The dataset contains **1,200 records and 14 columns**.

### Main Features

| Column           | Description                               |
| ---------------- | ----------------------------------------- |
| Order ID         | Unique order identifier                   |
| Date             | Order date                                |
| Customer ID      | Customer identifier                       |
| Product          | Product purchased                         |
| Quantity         | Number of units purchased                 |
| Unit Price       | Price per unit                            |
| Shipping Address | Order shipping location                   |
| Payment Method   | Method used for payment                   |
| Order Status     | Current status of the order               |
| Tracking Number  | Order tracking identifier                 |
| Items in Cart    | Number of items in the cart               |
| Coupon Code      | Coupon applied to the order               |
| Referral Source  | Source through which the customer arrived |
| Total Price      | Total value of the order                  |
