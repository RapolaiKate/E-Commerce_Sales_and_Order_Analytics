# 📊 Excel Pivot Table Analysis

## Overview

This folder contains the Excel Pivot Table analysis completed for the **E-Commerce Sales & Order Analytics** project.

Pivot Tables were created using the cleaned e-commerce dataset to summarize sales and order data and identify important business patterns.

## 📈 Pivot Table Analysis

The analysis includes:

* **Monthly Sales Pivot Table**
* **Monthly Sales Trend**
* **Sales by Product**
* **Orders by Payment Method**
* **Sales by Referral Source**

## 🎯 Objectives

The Pivot Table analysis was performed to:

* Analyze monthly sales performance.
* Identify sales trends over time.
* Compare product sales.
* Analyze orders by payment method.
* Evaluate sales generated through different referral sources.
* Summarize transaction data for easier business analysis.

## 🛠️ Tool Used

**Microsoft Excel**
